# Allow Store Content From Packages for The Sims™ 3

This is a mod for The Sims™ 3 which makes store content be classified as store content even if it was installed via `.package` files in the `Mods` folder.

## Installation

### Prerequisites

- [MonoPatcher by Lazy Duchess](https://modthesims.info/d/687815) is a hard requirement for this mod to function.

### Step-by-step

1. Download the mod from from [https://github.com/just-harry/allow-store-content-from-packages-for-ts3/releases/download/v1.0.0/allow-store-content-from-packages-for-ts3.zip](https://github.com/just-harry/allow-store-content-from-packages-for-ts3/releases/download/v1.0.0/allow-store-content-from-packages-for-ts3.zip).
2. Install the mod as usual, by extracting the `.package` file within the `.zip` file into the game's `Mods\Packages` folders.
